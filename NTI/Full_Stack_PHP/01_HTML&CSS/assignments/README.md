# 🌐 HTML & CSS Assignments

A collection of **HTML & CSS assignments** completed as part of the **NTI Full Stack PHP** training program.

These assignments focus on building a strong foundation in frontend development, including HTML structure, forms, semantic elements, CSS styling, layouts, and responsive design.

---

## 📚 Assignments

### 👤 Personal Information Card

A simple personal information card built using **HTML and CSS**.

The project focuses on:

* Structuring content with HTML
* Creating a clean card layout
* Styling text and elements with CSS
* Working with spacing, borders, and alignment
* Creating a simple and organized user interface

📁 Project:

```text
Personal_Information_Card/
```

---

### 📝 Registration Form

A registration form created using **HTML and CSS**.

The project focuses on creating and styling form elements such as:

* Text inputs
* Email fields
* Password fields
* Radio buttons
* Checkboxes
* Select elements
* Submit buttons
* Form labels

📁 Project:

```text
Registration_Form/
```

---

## 🛠️ Technologies

No external frameworks or libraries are required for these assignments.
