Created a custom `math_utils.py` module containing reusable mathematical functions and practiced importing and using the module from a Python notebook.

---

### 2. File I/O

Practiced working with text files by:

* Opening files
* Reading file contents
* Writing data to files
* Appending new data
* Working with file paths
* Handling file operations safely

---

### 3. Exception Handling

Practiced handling runtime errors using Python's exception-handling mechanism:

```python
try:
    # Code that may raise an exception
except ValueError:
    # Handle invalid input
```

The exercises also include input validation to handle invalid user input and make programs more reliable.
