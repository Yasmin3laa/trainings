# 🚀 ITI — Web Development, Python & Gen AI

A comprehensive training track focused on **Web Development, Python, Databases, Django, and Generative AI** as part of the **Information Technology Institute (ITI)** training program.

This repository contains training materials, assignments, exercises, projects, and practical implementations developed throughout the track.

## 📚 Training Track

The training is organized into several technical modules covering both frontend and backend development.

