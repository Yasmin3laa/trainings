# 🍽️ Black Goose Bistro

A simple static restaurant webpage created as part of my **HTML practice** during the ITI Web Development training.

## 📖 About the Project

**Black Goose Bistro** is a beginner-friendly restaurant webpage designed to practice the fundamentals of HTML and basic webpage styling.

The project focuses on creating a structured and readable static webpage using HTML5.

## ✨ Features

* Restaurant name and introduction
* Restaurant description
* Catering information
* Location details
* Opening hours
* Restaurant image
* Structured content sections
* Basic webpage styling

## 🛠️ Technologies Used

* HTML5
* Inline CSS
